# KSHAMTA Product Requirements Document

This repository implements the KSHAMTA PRD supplied with this project: a Streamlit project-intelligence and workforce-analytics platform based solely on the three cleaned local datasets. Its central requirements are transparent derived project risk, independent workforce intelligence, simulated—not historical—resource recommendations, demo role authentication, and an evaluated scikit-learn attrition model. See `README.md` for the implemented architecture, methods, limitations, and operating instructions.
